# CodeIgniter 3 Boilerplate

Boilerplate project CodeIgniter 3 dengan struktur rapi dan fitur dasar yang sering dibutuhkan saat mengerjakan project backend freelance. Sistem login sudah disiapkan menggunakan **MD5** untuk keperluan setup cepat.

---

## ✨ Fitur

- Sistem login & logout (MD5 hashing)
- Template header/footer modular
- AJAX CRUD Ready (jQuery)
- Flash message & validasi form
- Struktur folder rapi: asset, upload, helper
- Role user dasar

---

## 🚀 Cara Install

### 1. Clone Project

```bash
git clone https://github.com/haxan100/BOLERPLATE_CI3.git
cd BOLERPLATE_CI3

2. Jalankan Composer

``
composer install
Pastikan kamu sudah install Composer terlebih dahulu.
``

3. Setup Database

Buat database baru di MySQL, misal: boilerplate_ci3

ubah di database.php

Import file SQL yang ada di database/boilerplate_ci3.sql
